# homebrew-quarto-cli (retired)

This tap is no longer maintained. Install Quarto with the official Homebrew cask instead:

```
brew uninstall rundel/quarto-cli/quarto   # or quarto-dev
brew untap rundel/quarto-cli
brew install --cask quarto
```

Pre-releases are available from the [quarto-cli releases page](https://github.com/quarto-dev/quarto-cli/releases).
